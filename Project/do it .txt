# MASTER PROMPT — FULL-STACK TASK MANAGEMENT SYSTEM

You are acting as a senior full-stack software engineer helping me develop my individual final project.

Your job is to help me build a professional, clean, maintainable, fully functional **Task Management System** inspired by Trello.

The project must contain:

* Backend: Node.js + Express.js
* Database: MongoDB + Mongoose
* Frontend: React
* Authentication: JWT
* Password hashing: bcrypt
* RESTful API
* Input validation
* Authorization
* Centralized error handling
* Filtering and pagination
* Responsive frontend
* Complete frontend/backend integration

Do NOT invent requirements that conflict with the specification below.

---

# 1. PROJECT OBJECTIVE

Build a full-stack Task Management System where authenticated users can:

1. Register and log in.
2. Create and manage boards.
3. Add members to boards.
4. Create lists inside boards.
5. Create tasks inside lists.
6. Assign tasks to users.
7. Change task status.
8. Edit and delete tasks.
9. Set due dates.
10. Filter tasks.
11. Navigate through a clean dashboard.
12. Manage their boards from a responsive React interface.

The application should feel like a simplified professional Trello-style project management application.

The goal is not to clone Trello exactly.

Prioritize:

* correctness
* clean architecture
* maintainability
* security
* REST API quality
* database design
* good UX
* understandable code

# 2. IMPORTANT DEVELOPMENT RULES

Follow these rules throughout the entire development process.

Before writing substantial code:

* inspect the current repository
* inspect existing files
* inspect package configuration
* inspect environment configuration
* inspect available tools
* identify whether the project is empty or partially implemented

If something already exists and is correct, reuse it.

Track:

* completed items
* remaining items

Do not introduce unnecessary complexity.

Avoid adding:

* microservices
* Redux unless genuinely necessary
* unnecessary abstractions
* complicated design patterns
* unnecessary dependencies
* unnecessary infrastructure

This is a student final project, not an enterprise distributed system.

After implementing each major feature:

1. run the relevant tests/checks

# 12. AUTHENTICATION

Implement:

```text
POST /api/auth/register
POST /api/auth/login
GET  /api/auth/me
```

Registration flow:

```text
request
↓
validate input
↓
check email
↓
hash password
↓
create user
↓
return safe user data + JWT
```

Login flow:

```text
request
↓
validate
↓
find user
↓
compare password
↓
generate JWT
↓
return token + safe user data
```

JWT payload should contain a minimal identifier such as:

```js
{
  userId: user._id
}
```

Do not put sensitive information inside the JWT.

---

# 13. AUTHORIZATION

Authentication is not enough.

Implement authorization checks.

Examples:

* only authenticated users can access protected endpoints
* only board members can access board data
* only board owner can perform owner-only operations
* only authorized users can create/update/delete related lists
* only authorized users can modify tasks
* a task cannot be assigned to a user who does not belong to the board

Do not rely only on frontend checks.

Authorization must be enforced on the backend.
